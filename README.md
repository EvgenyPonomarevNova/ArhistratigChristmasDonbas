# Архистратиг — Christmas campaign website

Charity campaign website for Christmas gifts to children in Donbas.

[Open website preview](https://evgenyponomarevnova.github.io/ArhistratigChristmasDonbas/)

## About

A campaign landing page presenting the initiative, gift selection and information about the charity.

## Status and scope

The static preview demonstrates the interface. Payment processing and fulfilment depend on the organization’s external systems.

## Run locally

Clone the repository and serve its root with a static HTTP server. For example, with Python installed:

```sh
git clone https://github.com/EvgenyPonomarevNova/ArhistratigChristmasDonbas.git
cd ArhistratigChristmasDonbas
python -m http.server 8080
```

Open [localhost:8080](http://localhost:8080). A static server previews HTML/CSS/JavaScript; it does not execute PHP or connect external form services.
